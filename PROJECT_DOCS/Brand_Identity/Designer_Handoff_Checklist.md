# TickR Designer Handoff Checklist

**Give this to any designer, dev, contractor, or agency before they touch anything.**

## Before You Start

Confirm you have access to:

* [ ] Primary logo (`TickR_Primary_Logo_Dark.png`)
* [ ] Mascot-only mark (`TickR_Mascot_Mark_Dark.png`)
* [ ] Wordmark-only logo (`TickR_Wordmark_Dark.png` + `TickR_Wordmark_Light.png`)
* [ ] TickR Blue (approved brand color)

If you don't have all four, **stop**.

---

## Logo Usage Rules

* [ ] Use the **Primary Logo** by default
* [ ] Use **Mascot-only** for icons, favicons, avatars, badges
* [ ] Use **Wordmark-only** for documents, schools, parents, press
* [ ] Maintain clear space equal to the height of the "T" in TickR

---

## Size & Layout

* [ ] Never shrink full logo beyond legibility
* [ ] Use mascot-only for small sizes
* [ ] Never stretch, skew, rotate, crop, or warp

---

## Color Rules

* [ ] Use approved TickR Blue only
* [ ] Dark backgrounds: standard logo
* [ ] Light backgrounds: approved light wordmark
* No gradients
* No recolors
* No glow, shadow, or outline effects

---

## Mascot Rules

* [ ] Arrow must remain intact
* [ ] No props, emojis, or jokes
* [ ] No altered expressions in logo usage
* [ ] Fun skins allowed only **inside the app**, never as brand marks

---

## Final Check (Mandatory)

Ask:

> "Would this look appropriate in a school presentation or parent email?"

If not, revise.
