## 🎯 Overview

Create 5 custom illustrations featuring Tick (the TickR mascot) to make the landing page, onboarding, and feature sections visually engaging for kids (12-16) and reassuring to parents. All images should match the existing Tick character style (friendly robot with upward arrow) while feeling premium and modern.

**Reference Assets Already Available:**
- Existing Tick mascot character (use as style guide)
- TickR wordmark (bold, modern typography)
- Current color palette: Dark navy (#0f1628), Sapphire (#0ea5e9), Emerald (#10b981), Gold (#fbbf24)

## 📋 IMAGE #1: HERO ILLUSTRATION (Landing Page Hero Section)

### Purpose
Main hero image above fold on landing page. Should be eye-catching, show growth/momentum, and instantly communicate "investing + learning + growth" to both kids and adults.

### Dimensions
- **Size:** 1200px wide × 800px tall
- **Format:** PNG with transparency (preferred) or JPG
- **DPI:** 72 DPI (web)

### Content Description
**Tick (the robot mascot) riding/standing on an upward trending chart/stock graph**

**Specific Details:**
- Tick is in the CENTER-RIGHT of the image, animated pose (mid-jump or standing triumphantly)
- Tick's upward arrow (that's on his body) should align with or point toward the rising chart line
- Behind Tick: A large, upward-trending candlestick chart or line graph
- Chart colors: Use emerald green (#10b981) for the upward line, dark navy (#0f1628) for grid lines
- Tick's colors: Keep existing color scheme (light blue robot, darker blue outlines)
- Background: Dark navy (#0f1628) fading to slightly lighter navy, or subtle gradient
- Mood: Celebratory but professional. Tick looks happy/confident, not hyper-excited

**Style Notes:**
- Illustration style should match existing Tick mascot (friendly, clean lines, slightly modern/geometric)
- No 3D effects, keep it 2D and crisp
- Add subtle glow or light effects around Tick to make it pop against dark background
- Include subtle details: small upward arrows, coins/money symbols floating around (but not overwhelming)

**Use Case:**
This image will be positioned behind/beside the main headline "Master Investing Without the Risk" on the landing page hero section.

## 🎨 Style Guide for ALL Images

### Character Consistency
- Use the existing Tick mascot as your reference
- Tick should always be recognizable and consistent across all images
- Keep Tick's personality: friendly, approachable, smart, not condescending

### Color Palette (DO NOT deviate)
- **Primary Dark:** #0f1628 (navy background)
- **Accent Blue:** #0ea5e9 (sapphire - for data, UI, primary elements)
- **Success Green:** #10b981 (emerald - for growth, progress, wins)
- **Highlight Gold:** #fbbf24 (gold - for achievements, unlocks, special moments)
- **Dark Accent:** #141e2f (slightly lighter navy for depth)
- **Whites/Grays:** #e5e7eb (light gray for text), #ffffff (pure white accents)

### Visual Style Guidelines
- **Illustration Type:** 2D, modern, clean
- **Line Weight:** Consistent, crisp lines (not fuzzy)
- **Effects:** Minimal glows/shadows okay, but not excessive
- **Gradients:** Use sparingly, only for backgrounds/depth
- **Perspective:** Mostly flat with subtle depth cues
- **Complexity:** 60% of image should be detailed/focused, 40% can be simpler backgrounds

### Tone & Mood
- Professional enough for parents to respect
- Fun enough for kids to enjoy
- Inspiring without being hype-y or fake
- Celebrate growth and learning, not just winning
- Inclusive (show diversity in background characters when applicable)

### Technical Requirements
- **Format:** PNG with transparency (preferred) or JPG
- **Resolution:** 72 DPI for web (not print)
- **Color Mode:** RGB (not CMYK)
- **File Naming:** `tickr_[image_name]_[width]x[height].png`
  - Example: `tickr_hero_1200x800.png`
