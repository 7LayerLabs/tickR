# Onboarding Flow (CRITICAL)

## Step 1: Identity
- **Username** (no real names)
- **Age band** (12–13, 14–15, 16)
- Design: Card-based, single question per screen

## Step 2: Starter Sectors (Immediate Hook)
Unlocked day one:
- Tech
- Fashion & Lifestyle
- Entertainment & Gaming
- Everyday Brands

**Hook Language:** "Start with brands you already know."

## Step 3: Portfolio Setup
- Start with **$10,000 play money**
- Explain: Market is real, prices are real
- Explain: You're buying real stocks, real shares (simulated)
- Design: Show first purchase example (Nike, Apple, etc.)

## Step 4: Expectations (Fast, Clear)
Set realistic mental models:
- Prices go up and down
- You won't win every day
- **Learning > winning**

**Design Notes:**
- No walls of text
- Cards + icons only
- One concept per screen
- Clear CTAs to next step

## Output After Onboarding
- User account created
- Age group flagged
- $10k portfolio initialized
- Starter sectors unlocked
- Ready to view portfolio & buy stocks
