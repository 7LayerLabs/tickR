# Portfolio Screen (Core Screen)

This is the heartbeat of TickR.

## Key Metrics to Display

1. **Total Portfolio Value**
   - Display prominently at top
   - Real-time update on market hours

2. **Daily Change**
   - Display as % and $
   - Color coded: Green = up, Red = down

3. **Holdings**
   - List of shares owned
   - Click-through to individual stock pages
   - Show: Ticker, # of shares, current value, daily change

4. **Diversification Bar**
   - Visual indicator of sector spread
   - Show % allocation by sector
   - Encourage balanced portfolios

## Non-Negotiable Language

The language kids see shapes confidence and mental models:
- "You own 5 shares of Nike"
- "Your portfolio value is $10,430"
- "You gained $430 today"
- "Tech makes up 35% of your portfolio"

**Never use:** "Your account," "Holdings summary," or accounting jargon.

## Interaction Patterns

- Tap any holding → Stock detail page
- Swipe/scroll → See all holdings
- Button: "Buy More Stocks"
- Button: "Learn" (links to relevant lesson)

## Data Requirements

- Real-time stock prices
- Current portfolio allocation
- Daily % change calculation
- Sector assignment for each stock
